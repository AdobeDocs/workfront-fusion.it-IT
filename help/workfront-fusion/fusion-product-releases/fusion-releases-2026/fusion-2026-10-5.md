# Attività di rilascio di Workfront Fusion: settimana del 5 ottobre 2026

Questa pagina descrive tutti i miglioramenti apportati ad Adobe Workfront Fusion la settimana del 5 ottobre 2026.

Per un elenco di tutte le modifiche recenti, consulta [Attività sulla versione di Adobe Workfront Fusion](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md).

Per un elenco delle correzioni di bug recenti in Workfront Fusion, consulta la pagina [Aggiornamenti di manutenzione di Workfront](https://experienceleague.adobe.com/it/docs/workfront-known-issues/releases/current-updates) e controlla la presenza di eventuali aggiornamenti etichettati Aggiornamento di manutenzione di Workfront Fusion.

## Connettore Jira: nuovi tipi di connessione dell’account di servizio

Per semplificare la creazione di connessioni Jira corrispondenti alle modalità di autenticazione del team, al connettore Jira sono stati aggiunti due nuovi tipi di connessione: Token API dell’account di servizio e Account di servizio OAuth 2.

Queste opzioni consentono di creare connessioni per l’automazione che devono essere eseguite come account del servizio Jira dedicato invece che come account utente personale. Utilizza il token API dell’account di servizio quando l’account del servizio Jira si autentica con un token API e utilizza l’account di servizio OAuth 2 quando l’ambiente utilizza OAuth 2 per l’account di servizio.

I tipi di connessione Basic e OAuth2 sono ancora disponibili.

Per ulteriori informazioni, vedere [Moduli Jira](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/jira-modules-new.md).

## Nuovo modulo Crea più annotazioni disponibile per il connettore Veeva Vault

Per semplificare l’utilizzo del modulo Creazione di più annotazioni, è stato aggiornato a un nuovo modulo. Ora è possibile selezionare campi per contrassegni, riferimenti e altri campi di annotazioni prima di fornire i valori, semplificando la configurazione e concentrandola solo sui valori da assegnare come priorità.

È ancora disponibile il modulo Create Multiple Annotations (Creare più annotazioni), precedentemente disponibile, contrassegnato come &quot;Legacy&quot; (Legacy).

Per ulteriori informazioni sui moduli Veeva Vault, vedere [Moduli Veeva Vault](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/veeva-vault-modules.md).

## Aggiungi l’autenticazione JWT firmata alle richieste HTTP con il modulo HTTP > Crea una richiesta JWT

Per semplificare la chiamata delle API che richiedono l’autenticazione JWT firmata, è stato aggiunto il modulo di richiesta HTTP > Crea JWT.

Questo modulo funziona come il modulo standard HTTP > Crea una richiesta, ma genera e firma automaticamente un token web JSON dalle attestazioni fornite e lo include nella richiesta, per impostazione predefinita come token Bearer di autorizzazione. Questo consente di autenticarsi in servizi che richiedono un accesso basato su JWT di breve durata senza creare un passaggio di generazione di token separato nello scenario.

Per ulteriori informazioni, consulta [HTTP > Creare un modulo di richiesta JWT](/help/workfront-fusion/references/apps-and-modules/universal-connectors/http-module-make-a-jwt-request.md).
