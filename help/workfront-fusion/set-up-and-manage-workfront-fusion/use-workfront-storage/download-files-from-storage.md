# Scaricare i file dall&#39;archiviazione

Utilizzando l’area di archiviazione Fusion, puoi scaricare file dallo storage Adobe.

Per una panoramica dell&#39;archiviazione, vedere [Panoramica archiviazione](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

## Scaricare un file

1. In Workfront Fusion, fai clic su **Archiviazione** nell&#39;area di navigazione a sinistra.
1. Passare all&#39;archivio e alla cartella che contiene il file che si desidera scaricare.
1. Selezionare un file facendo clic su di esso nella tabella.
1. Nella barra delle azioni visualizzata fare clic su **Scarica**.

Un banner **avanzamento** viene visualizzato in alto a destra:

* Nome file
* Percentuale di avanzamento del download
* Byte trasferiti
* Un pulsante **Annulla** per interrompere il download

Il file viene salvato nel percorso di download predefinito del browser.

## Scaricare una versione specifica di un file

1. In Workfront Fusion, fai clic su **Archiviazione** nell&#39;area di navigazione a sinistra.
1. Passare all&#39;archivio e alla cartella che contiene il file che si desidera scaricare.
1. Selezionare un file e fare clic su **&quot;Versioni&quot;** nella barra delle azioni.
1. Nel pannello **Cronologia versioni**, fai clic su **Scarica** accanto alla versione che desideri scaricare.

Se il download non riesce, viene visualizzata una notifica popup: *&quot;Download non riuscito. Impossibile scaricare il file. Riprovare.&quot;*

Per ulteriori informazioni sulle versioni dei file, vedere [Visualizzare la cronologia delle versioni dei file nell&#39;archivio](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/view-storage-file-version-history.md).
