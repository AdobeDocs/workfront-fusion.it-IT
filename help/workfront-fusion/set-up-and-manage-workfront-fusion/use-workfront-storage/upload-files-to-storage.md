# Carica file nell&#39;archiviazione

Puoi caricare un file nell’archiviazione cloud di Adobe dall’interno di Workfront Fusion utilizzando l’area di archiviazione.

Il caricamento è disponibile quando si esplora una cartella (non nell’elenco delle cartelle di livello superiore).

* Per una panoramica dell&#39;archiviazione, vedere [Panoramica archiviazione](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).
* Per istruzioni sulla creazione di uno scenario di caricamento, vedi [Creare scenari dall&#39;archiviazione](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/create-scenarios-from-storage.md).


## Caricare un file

1. In Workfront Fusion, fai clic su **Archiviazione** nell&#39;area di navigazione a sinistra.
1. Passa all’archivio e alla cartella in cui desideri caricare un file.
1. Fare clic sul pulsante a discesa **&quot;Carica file&quot;**.
1. Selezionare **&quot;Carica file&quot;** per caricarlo direttamente.

   Viene aperto un selettore di file.
1. Seleziona il file da caricare.

   Un banner **avanzamento** viene visualizzato in alto a destra:

   * Nome file
   * Percentuale di avanzamento del caricamento
   * Byte trasferiti
   * Un pulsante **Annulla** per interrompere il caricamento

Dopo il caricamento, il file viene visualizzato nell’elenco delle cartelle. La colonna **Size** potrebbe mostrare temporaneamente *&quot;Elaborazione in corso...&quot;* mentre l&#39;archiviazione Adobe elabora il file nel backend. Al termine dell’elaborazione, viene visualizzata la dimensione effettiva del file. Per verificare questo aspetto, aggiorna la pagina.

## Limiti di caricamento

* Dimensione massima file: **5 GB**.
