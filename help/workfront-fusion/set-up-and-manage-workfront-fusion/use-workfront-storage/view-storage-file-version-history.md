# Visualizzare la cronologia delle versioni dei file in Archiviazione

Per una panoramica dell&#39;archiviazione, vedere [Panoramica archiviazione](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md).

I file nell’archiviazione Adobe possono avere più versioni.

## Visualizzazione cronologia versioni

1. In Workfront Fusion, fai clic su **Archiviazione** nell&#39;area di navigazione a sinistra.
1. Passare al repository e alla cartella che contiene il file per il quale si desidera visualizzare le versioni.
1. Selezionare un file e fare clic su **&quot;Versioni&quot;** dalla barra delle azioni.
Viene aperto un pannello **Cronologia versioni**.
Le versioni sono elencate per prime come più recenti, ognuna delle quali mostra:
   * Numero di versione
   * Data
   * Un pulsante **Scarica**

   La versione corrente (più recente) è etichettata con un distintivo **&quot;current&quot;**

Per scaricare una versione specifica, vedere [Scaricare una versione specifica](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/download-files-from-storage.md#download-a-specific-version) nell&#39;articolo Scaricare i file dall&#39;archivio.
